# Fonts

Pocket uses **JetBrains Mono Nerd Font** (JetBrains Mono 2.304, patched by Nerd Fonts 3.4.0).
The files are bundled here so the app looks the same offline and on PCs without the font installed.

- Weights used: Medium (500), Bold (700), ExtraBold (800).
